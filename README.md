# incident-triage-dashboard

A clean **React + Vite** single-page dashboard for inspecting, filtering, and exporting JSON triage and QA reports generated by security, evaluation, hardware, or data-audit tools.

## Features

- **JSON Report Loader:** Load any JSON audit report (`findings` or `issues` arrays) directly in the browser, or explore with the built-in sample dataset.
- **Severity & Keyword Filtering:** Filter findings by severity (`CRITICAL`, `HIGH`, `ERROR`, `WARN`, `MEDIUM`) and search across rule IDs, IPs/targets, descriptions, and evidence snippets.
- **Filtered Export:** Download the currently filtered subset as `filtered_triage_findings.json`.

## Quickstart

```bash
git clone [https://github.com/B5IVE/incident-triage-dashboard.git](https://github.com/B5IVE/incident-triage-dashboard.git)
cd incident-triage-dashboard
